# 2841. 几乎唯一子数组的最大和

## 题目描述

给你一个整数数组 `nums` 和两个正整数 `m` 和 `k`。

请你返回 `nums` 中长度为 `k` 的 **几乎唯一** 子数组的 **最大和**,如果不存在几乎唯一子数组,请你返回 `0`。

如果 `nums` 的一个子数组有至少 `m` 个互不相同的元素,我们称它是 **几乎唯一** 子数组。

子数组指的是一个数组中一段连续 **非空** 的元素序列。

> **示例 1**
>
> **输入**:`nums = [2,6,7,3,1,7]`, `m = 3`, `k = 4`
>
> **输出**:`18`
>
> **解释**:总共有 3 个长度为 `k = 4` 的几乎唯一子数组。分别为 `[2, 6, 7, 3]`、`[6, 7, 3, 1]` 和 `[7, 3, 1, 7]`。这些子数组中,和最大的是 `[2, 6, 7, 3]`,和为 18。
>
> **示例 2**
>
> **输入**:`nums = [5,9,9,2,4,5,4]`, `m = 1`, `k = 3`
>
> **输出**:`23`
>
> **解释**:总共有 5 个长度为 `k = 3` 的几乎唯一子数组。分别为 `[5, 9, 9]`、`[9, 9, 2]`、`[9, 2, 4]`、`[2, 4, 5]` 和 `[4, 5, 4]`。这些子数组中,和最大的是 `[5, 9, 9]`,和为 23。
>
> **示例 3**
>
> **输入**:`nums = [1,2,1,2,1,2,1]`, `m = 3`, `k = 3`
>
> **输出**:`0`
>
> **解释**:输入数组中不存在长度为 `k = 3` 的子数组含有至少 `m = 3` 个互不相同元素的子数组。所以不存在几乎唯一子数组,最大和为 0。

**提示**：

- `1 <= nums.length <= 2 * 10^4`
- `1 <= m <= k <= nums.length`
- `1 <= nums[i] <= 10^9`

---

## 解题思路

看见数组里的定长子数组，就能考虑使用定长滑动窗口了。

但本题存在一个新概念，需要仔细判断其规则：注意到“互不相同元素“，那么答案的判定和记录必然与元素存在性和计数相关，需使用哈希表。

### 算法步骤

1. 入：元素和 `+= nums[i]`，`nums[i]`元素计数++。
2. 更新答案：满足窗口内元素种类 `>= m` 时,更新答案为 `max(ans, sum)`。
3. 出：元素和 `-= nums[left]`，`nums[left]` 元素计数减一，若减到 0，则从哈希表中删除该元素。

---

## 代码

```cpp
class Solution {
public:
    long long maxSum(vector<int>& nums, int m, int k) {
        int n = nums.size();
        unordered_map<int, int> hash;
        long long sum = 0, ans = 0;

        for(int i = 0; i < n; i++){
            //入
            sum += nums[i];
            hash[nums[i]]++;

            int left = i - k + 1;
            if(left < 0){
                continue;
            }

            //答案
            if(hash.size() >= m){
                ans = max(sum, ans);
            }

            //出
            sum -= nums[left];
            if(--hash[nums[left]] == 0){
                hash.erase(nums[left]);
            }
        }

        return ans;
    }
};
```

- **时间复杂度**: O(n)
- **空间复杂度**: O(k)，哈希表大小不会超过窗口大小

## 边界自测

- nums=[1000000000,999999999,999999998], m=3, k=3 → 2999999997；总和需要 64 位。
