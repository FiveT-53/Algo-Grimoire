# 2461. 长度为 K 子数组中的最大和

[LeetCode 2461. 长度为 K 子数组中的最大和](https://leetcode-cn.com/problems/maximum-sum-of-distinct-subarrays-with-length-k/)

## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`。请你从 `nums` 中满足下述条件的全部子数组中找出最大子数组和:

- 子数组的长度是 `k`,且
- 子数组中的所有元素 **各不相同**。

返回满足题面要求的最大子数组和。如果不存在子数组满足这些条件,返回 `0`。

**子数组** 是数组中一段连续非空的元素序列。

> **示例 1**
>
> **输入**:`nums = [1,5,4,2,9,9,9]`, `k = 3`
>
> **输出**:`15`
>
> **解释**:`nums` 中长度为 3 的子数组是:
> -`[1,5,4]` 满足全部条件,和为 10。
> -`[5,4,2]` 满足全部条件,和为 11。
> -`[4,2,9]` 满足全部条件,和为 15。
> -`[2,9,9]` 不满足全部条件,因为元素 9 出现重复。
> -`[9,9,9]` 不满足全部条件,因为元素 9 出现重复。
>
> 因为 15 是满足全部条件的所有子数组中的最大子数组和,所以返回 15。
>
> **示例 2**
>
> **输入**:`nums = [4,4,4]`, `k = 3`
>
> **输出**:`0`
>
> **解释**:`nums` 中长度为 3 的子数组是:
> -`[4,4,4]` 不满足全部条件,因为元素 4 出现重复。
>
> 因为不存在满足全部条件的子数组,所以返回 0。

**提示**：

- `1 <= k <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`

## 解题思路

观察完发现和2841题类似，唯一区别在于更新答案时对窗口条件的判断是元素各不相同。依旧采用滑动窗口+哈希表解决。

### 算法步骤

1. 入：元素和 `+= nums[i]`，`nums[i]`元素计数++。
2. 更新答案：满足窗口内元素种类 `= k` 时,更新答案为 `max(ans, sum)`。
3. 出：元素和 `-= nums[i]`，`nums[i]`元素计数--，若--后为0，则从哈希表中删除该元素。

---

## 代码

```cpp
class Solution {
public:
    long long maximumSubarraySum(vector<int>& nums, int k) {
        int n = nums.size();
        unordered_map<int, int> hash;
        long long sum = 0, ans = 0;

        for(int i = 0; i < n; i++){
            //入
            sum += nums[i];
            hash[nums[i]]++;

            int left = i - k + 1;
            if(left < 0){
                continue;
            }

            //答案
            if(hash.size() == k){
                ans = max(sum, ans);
            }

            //出
            sum -= nums[left];
            if(--hash[nums[left]] == 0){
                hash.erase(nums[left]);
            }
        }

        return ans;
    }
};
```

- **时间复杂度**: O(n)
- **空间复杂度**: O(k)，哈希表大小不会超过窗口长度
