# 1493. 删掉一个元素以后全为 1 的最长子数组

<!-- 标签:不定长滑动窗口、数组 -->

**题目链接**：

[LeetCode 1493. 删掉一个元素以后全为 1 的最长子数组](https://leetcode-cn.com/problems/longest-subarray-of-1s-after-deleting-one-element/)

---

## 题目描述

给你一个二进制数组 `nums` ，你需要从中删掉一个元素。

请你在删掉元素的结果数组中，返回最长的且只包含 1 的非空子数组的长度。

如果不存在这样的子数组，请返回 0 。

> **示例 1**
>
> **输入**:`nums = [1,1,0,1]`
>
> **输出**:`3`
>
> **解释**:删掉位置 2 的数后，`[1,1,1]` 包含 3 个 1。
>
> **示例 2**
>
> **输入**:`nums = [0,1,1,1,0,1,1,0,1]`
>
> **输出**:`5`
>
> **解释**:删掉位置 4 的数字后，`[0,1,1,1,1,1,0,1]` 的最长全 1 子数组为 `[1,1,1,1,1]`。
>
> **示例 3**
>
> **输入**:`nums = [1,1,1]`
>
> **输出**:`2`
>
> **解释**:你必须要删除一个元素。

**提示**：

- `1 <= nums.length <= 10^5`
- `nums[i]` 要么是 `0` 要么是 `1`。

---

## 解题思路

题目可以转化成：求 `nums` 中最长的子数组，子数组中最多包含一个 `0`。

→ 不定长滑动窗口问题，套用常规套路即可。

### 关键观察

题目要求必定会删掉一个元素，因此即便 `nums` 中全为 `1`，也不影响计数，窗口长度永远都是 `right - left (+ 1 - 1)`。

### 算法步骤

1. for循环依旧遍历右端点 `right`。
2. while循环处理条件和左端点 `left`，本题条件为窗口中的 `0` 数量不能超过 1。
3. while循环外才满足题目要求，更新答案 `ans`。

---

## 代码

```cpp
class Solution {
public:
    int longestSubarray(vector<int>& nums) {
        int n = nums.size(), left = 0, ans = 0, count = 0;

        for(int right = 0; right < n; right++){
            if(nums[right] == 0){
                count++;
            }

            while(count > 1){
                if(nums[left] == 0){
                    count--;
                }
                left++;
            }

            ans = max(ans, right - left);
        }

        return ans;
    }
};
```

- **时间复杂度**: O(n)
- **空间复杂度**: O(1)

---

## 易错点

- 题目删除掉一个元素，因此窗口长度要减去 1。

## 边界自测

- nums=[1,1,1] → 2；全为 1 也必须删除一个。
