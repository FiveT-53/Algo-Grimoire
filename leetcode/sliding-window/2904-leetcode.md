# 2904. 最短且字典序最小的美丽子字符串

## 题目描述

给你一个二进制字符串 `s` 和一个正整数 `k`。

如果 `s` 的某个子字符串中 `1` 的个数恰好等于 `k`，则称这个子字符串是一个 **美丽子字符串**。

令 `len` 等于 **最短** 美丽子字符串的长度。

返回长度等于 `len` 且字典序 **最小** 的美丽子字符串。如果 `s` 中不含美丽子字符串，则返回一个 **空** 字符串。

对于相同长度的两个字符串 `a` 和 `b`，如果在 `a` 和 `b` 出现不同的第一个位置上，`a` 中该位置上的字符严格大于 `b` 中的对应字符，则认为字符串 `a` 字典序 **大于** 字符串 `b`。

- 例如，`"abcd"` 的字典序大于 `"abcc"`，因为两个字符串出现不同的第一个位置对应第四个字符，而 `d` 大于 `c`。

> **示例 1**
>
> **输入**:`s = "100011001"`, `k = 3`
>
> **输出**:`"11001"`
>
> **解释**:示例中共有 7 个美丽子字符串(下划线标注子串):
>
> - 子字符串 `100011001` 中的 `100011`。
> - 子字符串 `100011001` 中的 `1000110`。
> - 子字符串 `100011001` 中的 `10001100`。
> - 子字符串 `100011001` 中的 `00011001`。
> - 子字符串 `100011001` 中的 `0011001`。
> - 子字符串 `100011001` 中的 `011001`。
> - 子字符串 `100011001` 中的 `11001`。
>
> 最短美丽子字符串的长度是 5。长度为 5 且字典序最小的美丽子字符串是 `"11001"`。
>
> **示例 2**
>
> **输入**:`s = "1011"`, `k = 2`
>
> **输出**:`"11"`
>
> **解释**:示例中共有 3 个美丽子字符串(下划线标注子串):
>
> - 子字符串 `1011` 中的 `101`。
> - 子字符串 `1011` 中的 `011`。
> - 子字符串 `1011` 中的 `11`。
>
> 最短美丽子字符串的长度是 2。长度为 2 且字典序最小的美丽子字符串是 `"11"`。
>
> **示例 3**
>
> **输入**:`s = "000"`, `k = 1`
>
> **输出**:`""`
>
> **解释**:示例中不存在美丽子字符串。

**提示**：

- `1 <= s.length <= 100`
- `1 <= k <= s.length`

## 解题思路

找符合某种条件的最短子串，那基本就能确定是非定长滑动窗口了。不过这题仔细一看要求还挺多，不仔细思考的话很容易搞不清楚判断条件和判断位置。

### 关键观察

条件：

- 子字符串中 `1` 的个数恰好等于 `k` → 维护计数器
- 子字符串的长度最短 → 既然要求长度最短，结合第一个条件可知，答案的左侧端点必定是 `1` 的位置，左侧的 `0` 都可以收缩
- 子字符串的字典序最小 → 直接用 `<` 比较即可，进阶方法可以使用字符串哈希（或者后缀数组等），可以把单次比较字典序的时间降至 O(logn)

### 算法步骤

1. 因为答案是字符串，要求的又是最短，初始化不如数字类型方便，所以初始化为 `s`，做特别判断是否返回空字符串。
2. 开始滑动窗口，for 循环右侧端点，维护计数器 `count1`。
3. while循环收缩左侧端点（1.计数大于k收缩；2.左侧0收缩），维护计数器 `count1`。
4. 收缩后判断是否恰好满足条件（`count1 == k`），如果满足，尝试更新答案（更新条件为：1.当前子字符串长度更短 或 2.长度相同但字典序更小）。

## 代码

```cpp
class Solution {
public:
    string shortestBeautifulSubstring(string s, int k) {
        //提前判空返回空
        if(ranges::count(s, '1') < k){
            return "";
        }

        int n = s.length(), left = 0, count1 = 0;
        string ans = s;

        for(int right = 0; right < n; right++){
            //右侧端点入
            count1 += s[right] - '0';

            //左端收缩：1.计数大于k收缩；2.左侧0收缩
            while(count1 > k || s[left] == '0'){
                count1 -= s[left] - '0';
                left++;
            }

            //收缩后判断是否恰好满足条件，尝试更新答案
            if(count1 == k){
                string t = s.substr(left, right - left + 1);
                //更新答案：1.当前子字符串长度更短 或 2.长度相同但字典序更小
                if(t.length() < ans.length() || t.length() == ans.length() && t < ans){
                    ans = move(t);
                }
            }
        }
        return ans;
    }
};
```

- **时间复杂度**: O(n²)，其中 n 为 s 的长度。
- **空间复杂度**: O(1)。
