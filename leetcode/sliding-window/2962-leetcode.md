# 2962. 统计最大元素至少出现 K 次的子数组

<!-- 标签:不定长滑动窗口、数组 -->

**题目链接**：

[LeetCode 2962. 统计最大元素至少出现 K 次的子数组](https://leetcode-cn.com/problems/count-subarrays-where-max-element-appears-at-least-k-times/)

---

## 题目描述

给你一个整数数组 `nums` 和一个 **正整数** `k`。

请你统计有多少满足 「 `nums` 中的 **最大** 元素」至少出现 `k` 次的子数组，并返回满足这一条件的子数组的数目。

子数组是数组中的一个连续元素序列。

> **示例 1**
>
> **输入**:`nums = [1,3,2,3,3]`, `k = 2`
>
> **输出**:`6`
>
> **解释**:包含元素 3 至少 2 次的子数组为:`[1,3,2,3]`、`[1,3,2,3,3]`、`[3,2,3]`、`[3,2,3,3]`、`[2,3,3]` 和 `[3,3]`。
>
> **示例 2**
>
> **输入**:`nums = [1,4,2,1]`, `k = 3`
>
> **输出**:`0`
>
> **解释**:没有子数组包含元素 4 至少 3 次。

**提示**：

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^6`
- `1 <= k <= 10^5`

---

## 解题思路

子数组 → 连续 → 滑动窗口。

再看条件：子数组至少包含 `k` 次的 `nums` 中的 **最大** 元素，依旧是越大越满足的计数，因此采用此类题型“先缩小，再+ `left`”的方法完成。

### 关键观察

需特别注意本题的”最大“指的是整个数组的最大元素，不是子数组的最大元素。在算法中维护一个计数器即可。

### 算法步骤

1. for循环：右端点遍历数组 `nums`，每次入窗口一个元素，判断是否为最大元素。
2. while循环：当窗口满足条件时，收缩左端点直到恰好不满足条件。
3. 更新答案：每次收缩完成之后，符合条件的子数组数量为 `left`，所以 `ans += left`。

---

## 代码

```cpp
class Solution {
public:
    long long countSubarrays(vector<int>& nums, int k) {
        int mx = ranges::max(nums);
        long long ans = 0;
        int cnt = 0, left = 0;

        for(int right = 0; right < nums.size(); right++){
            //入
            if(nums[right] == mx){
                cnt++;
            }

            //缩
            while(cnt >= k){
                if(nums[left] == mx){
                    cnt--;
                }
                left++;
            }

            //答案
            ans += left;
        }

        return ans;
    }
};
```

- **时间复杂度**: O(n)
- **空间复杂度**: O(1)

---

## 易错点

- 注意审题：本题的最大值指的是整个数组的最大元素，不是子数组的最大元素。
- 注意更新答案时，`ans += left`，因为每次收缩完成之后，符合条件的子数组数量为 `left`。

## 边界自测

- nums=[1], k=2 → 0；最大元素出现次数不足。
