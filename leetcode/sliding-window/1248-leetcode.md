## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`。如果某个连续子数组中恰好有 `k` 个奇数数字，我们就认为这个子数组是「**优美子数组**」。

请返回这个数组中 **「优美子数组」** 的数目。

> **示例 1**
>
> **输入**:`nums = [1,1,2,1,1]`, `k = 3`
>
> **输出**:`2`
>
> **解释**:包含 3 个奇数的子数组是 `[1,1,2,1]` 和 `[1,2,1,1]`。
>
> **示例 2**
>
> **输入**:`nums = [2,4,6]`, `k = 1`
>
> **输出**:`0`
>
> **解释**:数列中不包含任何奇数，所以不存在优美子数组。
>
> **示例 3**
>
> **输入**:`nums = [2,2,2,1,2,2,1,2,2,2]`, `k = 2`
>
> **输出**:`16`

**提示**：

- `1 <= nums.length <= 50000`
- `1 <= nums[i] <= 10^5`
- `1 <= k <= nums.length`

---

## 解题思路

连续子数组 → 不定长滑动窗口

再看子数组条件：恰好有 `k` 个奇数数字，要求符合条件的子数组数量。看到这样的恰好的数量题型就可以考虑分别求大于等于 `k` 个奇数和大于 `k` 个奇数的子数组数量，再做减法。

### 关键观察

在for循环中的两部分内容本质上可以进行不同程度的合并，在本题中，入的部分进行合并将节省一次取模操作和条件判断，节省更多时间。

### 算法步骤

1. for循环：维护 `right`，遍历数组，入元素。
2. >=部分：当 `cnt1 >= k` 时移出左端元素，仅移出奇数才令 `cnt1--`；收缩结束后 `ans += left1`。
3. >部分：当 `cnt2 > k` 时移出左端元素，仅移出奇数才令 `cnt2--`；收缩结束后 `ans -= left2`。

---

## 代码

```cpp
class Solution {
public:
    int numberOfSubarrays(vector<int>& nums, int k) {
        int ans = 0;
        int left1 = 0, left2 = 0;
        int cnt1 = 0, cnt2 = 0;

        for(int right = 0; right < nums.size(); right++){
            //入
            if(nums[right] % 2 == 1){
                cnt1++;
                cnt2++;
            }

            //>=部分收缩和答案
            while(left1 <= right && cnt1 >= k){
                if(nums[left1] % 2 == 1){
                    cnt1--;
                }
                left1++;
            }

            ans += left1;

            //>部分收缩和答案
            while(cnt2 > k){
                if(nums[left2] % 2 == 1){
                    cnt2--;
                }
                left2++;
            }
            ans -= left2;
        }

        return ans;
    }
};
```

- **时间复杂度**: O(n)
- **空间复杂度**: O(1)
