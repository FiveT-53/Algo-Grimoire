# 2379. 得到 K 个连续黑块的最少涂色次数

**题目链接：**

[LeetCode 2379. 得到 K 个连续黑块的最少涂色次数](https://leetcode-cn.com/problems/minimum-recolors-to-get-k-consecutive-black-blocks/)

---

## 题目描述

给你一个长度为 `n` 的字符串 `blocks`,其中 `blocks[i]` 要么是 `'W'` 要么是 `'B'`,分别表示白色和黑色块。

我们希望操作这个字符串,使其包含长度为 `k` 的连续黑色块。最少需要多少次涂色操作(将一个 `'W'` 改成 `'B'`)?

**字符串中只包含字符 `'W'` 和 `'B'`。**

> **示例 1**
>
> **输入**:`blocks = "WBBWWBBWBW"`, `k = 7`
>
> **输出**:`3`
>
> **解释**:一种得到 7 个连续黑块的方法是:
> 把第 0、3 和 4 个块涂成黑色,变成 `"BBBBBBBWBW"`。
> 下标 0 到 6 构成长度为 7 的连续黑块。
> 综上,共需要最少 3 次涂色。
>
> **示例 2**
>
> **输入**:`blocks = "WBBWWBBWBW"`, `k = 8`
>
> **输出**:`3`
>
> **解释**:选择下标 1 到 8 的窗口，只需将下标 3、4、7 的三个白块涂黑；三个候选窗口的白块数分别为 4、3、4。
>
> **示例 3**
>
> **输入**:`blocks = "WBWBBBWBBW"`, `k = 9`
>
> **输出**:`3`
>
> **解释**:两个长度为 9 的窗口都含 3 个白块，因此最少涂色 3 次。

**提示**：

- `n == blocks.length`
- `1 <= n <= 100`
- `blocks[i]` 要么是 `'W'`,要么是 `'B'`
- `1 <= k <= n`

---

## 解题思路

一开始看到有点懵，但是能明显注意到长度固定为 `k` ，又要的是连续，那么就考虑使用定长滑动窗口了。有了初步的判断后再来读题，题目要的结果就很显而易见了。

### 算法步骤

1. 入：判断位置 `i` 处 是否为白色块，如果是则 `count++`。
2. 更新答案：“当前窗口内白色块的数量”与”当前答案“的较小值。
3. 出：判断位置 `i - k + 1` 处 是否为白色块，如果是则 `count--`。

---

## 代码

```cpp
class Solution {
public:
    int minimumRecolors(string blocks, int k) {
        int n = blocks.size();
        int count = 0, res = INT_MAX;

        for(int i = 0; i < n; i++){
            //入
            if(blocks[i] == 'W'){
                count++;
            }
            int left = i - k + 1;
            if(left < 0){
                continue;
            }

            //答案
            res = min(res, count);

            //出
            if(blocks[left] == 'W'){
                count--;
            }
        }

        return res;
    }
};
```

- **时间复杂度**: O(n)
- **空间复杂度**: O(1)

## 易错点

- 在 ASCII 编码下，W 和 B 的最低位分别为 1 和 0，可用位运算区分；但本文保留更直观的字符比较。是否更快取决于编译器和运行环境，未经基准测试不能断言减少分支或提高性能。

- blocks="B", k=1 → 0；已满足条件不需要涂色。
