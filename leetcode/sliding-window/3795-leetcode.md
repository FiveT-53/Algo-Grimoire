# 3795. 不同元素和至少为 K 的最短子数组长度

<!-- 标签:不定长滑动窗口、哈希表、数组 -->

**题目链接**：

[LeetCode 3795. 不同元素和至少为 K 的最短子数组长度](https://leetcode-cn.com/problems/minimum-subarray-length-with-distinct-sum-at-least-k/)

---

## 题目描述

给你一个整数数组 `nums` 和一个整数 `k`。

返回一个 **子数组** 的 **最小** 长度，使得该子数组中出现的 **不同** 值之和（每个值只计算一次）**至少** 为 `k`。如果不存在这样的子数组，则返回 -1。

**子数组** 是数组中一个连续的 **非空** 元素序列。

> **示例 1**
>
> **输入**:`nums = [2,2,3,1]`, `k = 4`
>
> **输出**:`2`
>
> **解释**:子数组 `[2, 3]` 具有不同的元素 `{2, 3}`，它们的和为 `2 + 3 = 5`，这至少为 `k = 4`。因此，答案是 2。
>
> **示例 2**
>
> **输入**:`nums = [3,2,3,4]`, `k = 5`
>
> **输出**:`2`
>
> **解释**:子数组 `[3, 2]` 具有不同的元素 `{3, 2}`，它们的和为 `3 + 2 = 5`，这至少为 `k = 5`。因此，答案是 2。
>
> **示例 3**
>
> **输入**:`nums = [5,5,4]`, `k = 5`
>
> **输出**:`1`
>
> **解释**:子数组 `[5]` 具有不同的元素 `{5}`，它们的和为 `5`，这至少为 `k = 5`。因此，答案是 1。

**提示**：

- `1 <= nums.length <= 10^5`
- `1 <= nums[i] <= 10^5`
- `1 <= k <= 10^9`

---

## 解题思路

一眼望穿不定长滑动窗口，读题时发现计数要求稍微复杂一些，其余套路即可解决。

### 关键观察

每个值只计算一次，就得用哈希表了，既然用了哈希表，那在计算总和时就可以用哈希表的计数来判断是否要计入和计出。

### 算法步骤

1. for循环遍历右端点 `right`，需要特别判断是否要计入总和。
2. while循环处理条件和左端点 `left`，本题合法条件为窗口中的不同元素和至少为 `k`，满足时尝试收缩。
3. 在while循环内，左端点收缩前，才满足题目要求，更新答案 `ans`。
4. 收缩左端点 `left`，需要特别判断是否要移出总和。

---

## 代码

```cpp
class Solution {
public:
    int minLength(vector<int>& nums, int k) {
        int n = nums.size(), left = 0, ans = INT_MAX;
        unordered_map<int, int> hash;
        long long sum = 0;

        for(int right = 0; right < n; right++){
            //入（查哈希-决定是否计入和）
            int r_num = nums[right];
            hash[r_num]++;
            if(hash[r_num] == 1){
                sum += r_num;
            }

            //收缩（≥k）
            while(sum >= k){
                //收缩前记录答案（满足条件）
                ans = min(ans, right - left + 1);
                int l_num = nums[left];
                hash[l_num]--;
                //需特别判断是否要移出总和
                if(hash[l_num] == 0){
                    sum -= l_num;
                }
                left++;
            }
        }

        return ans == INT_MAX ? -1 : ans;
    }
};
```

- **时间复杂度**: O(n)
- **空间复杂度**: O(n)

## 易错点

- 本题需考虑清楚总和的计算判断，避免重复计算。

## 边界自测

- nums=[2,2], k=5 → -1；重复值只贡献一次。
