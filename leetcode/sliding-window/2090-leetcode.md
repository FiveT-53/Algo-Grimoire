# 2090. 半径为 k 的子数组平均值

**题目链接：**

[LeetCode 2090. 半径为 k 的子数组平均值](https://leetcode-cn.com/problems/k-radius-subarray-averages/)

---

## 题目描述

给你一个下标从 0 开始的数组 `nums`,数组中有 `n` 个整数。另给你一个整数 `k`。

半径为 `k` 的子数组平均值 是指:`nums` 中以某个下标 `i` 为中心,半径为 `k` 的子数组的所有元素平均值,包括下标 `i` 本人。具体地说,半径为 `k` 的子数组平均值是一个长度为 `2k + 1` 的子数组(即`i - k` 到 `i + k`,共 `2k + 1` 个元素)的元素平均值。

当 `i - k < 0` 或 `i + k >= n` 时,该下标 `i` 处的半径为 `k` 的子数组平均值将视为 `-1`。

请你返回一个长度为 `n` 的数组 `avgs`,其中 `avgs[i]` 是以 `i` 为中心的半径为 `k` 的子数组平均值。

> **示例 1**
>
> ![2090 示例 1 示意](../../docs/images/2090-window-eg1.png)
>
> **输入**:`nums = [7,4,3,9,1,8,5,2,6]`, `k = 3`
>
> **输出**:`[-1,-1,-1,5,4,4,-1,-1,-1]`
>
> **解释**:
> -`avg[0]`、`avg[1]`、`avg[2]`、avg[7]、avg[8] 因为下标超出范围,所以为 `-1`。
> -下标 3 的子数组为 `[7,4,3,9,1,8,5]`,平均值 `(7+4+3+9+1+8+5)/7 = 5`。
> -下标 4 的子数组为 `[4,3,9,1,8,5,2]`,平均值 `(4+3+9+1+8+5+2)/7 = 32/7 = 4.57142857...`,向下取整后为 `4`。
> -下标 5 的子数组为 `[3,9,1,8,5,2,6]`,平均值 `(3+9+1+8+5+2+6)/7 = 34/7 = 4.85714285...`,向下取整后为 `4`。
>
> **示例 2**
>
> **输入**:`nums = [100000]`, `k = 0`
>
> **输出**:`[100000]`
>
> **解释**:下标 0 的子数组就是它本身,平均值就是它本身,即 `100000`。
>
> **示例 3**
>
> **输入**:`nums = [8]`, `k = 100000`
>
> **输出**:`[-1]`
>
> **解释**:`avg[0]` 为 `-1`,因为在下标 0 前后的元素数量均不足 `k` 个。

**提示**：

- `n == nums.length`
- `1 <= n <= 10^5`
- `0 <= nums[i]`, `nums[i] <= 10^5`
- `0 <= k <= 10^5`

---

## 解题思路

读题：子数组 -> 连续，考虑滑动窗口；半径为 k -> 窗口大小固定为 `2k + 1`；求平均值 -> 求和后除以窗口大小。
窗口条件满足，考虑使用定长滑动窗口，公式化三步走。

> 💡 读题时遗漏的点:窗口内的元素和可能超过 32 位整数的最大值(`nums[i] <= 10^5`、窗口大小最大为 `2*10^5+1`,极端情况 `2*10^5+1` 个 `10^5` 相加 ≈ `2*10^{10}`,超出 `int` 上界),需用 64 位整数(`long long`)保存窗口元素和。

### 算法步骤

1. 入：下标为 i 的元素进入窗口，窗口元素和 s 增加 nums[i]。如果 i < 2k 则重复第一步。
2. 本题只需记录答案，即 avgs[i−k]=s/(2k+1)。其中 i−k 是因为 i 对应的是子数组右端点，而记录答案的位置是子数组的正中间。
3. 出：下标为 i−2k 的元素离开窗口，窗口元素和 s 减少 nums[i−2k]。

## 代码

```cpp
class Solution {
public:
    vector<int> getAverages(vector<int>& nums, int k) {
        int n = nums.size();
        vector<int> avgs(n, -1);
        int len = 2 * k + 1;
        long long sum = 0;

        for(int i = 0; i < n; i++){
            //入
            sum += nums[i];
            int left = i - 2 * k;
            if(left < 0){
                continue;
            }

            //答案
            avgs[i - k] = sum / len;

            //出
            sum -= nums[left];
        }

        return avgs;
    }
};
```

- **时间复杂度**: O(n)
- **空间复杂度**: O(1)，返回值不计

## 易错点

- 遇到数字超范围，用 long long 来存储元素和，避免溢出。
- 考虑清楚窗口的左端点、右端点和窗口大小在题目中具体是多少。
